# NCS Explorer — frontend

React + TypeScript + Vite frontend for NCS Explorer. See the [root README](../README.md) for what the project does, and [`CLAUDE.md`](../CLAUDE.md) for architecture/conventions.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm run lint` — run ESLint
- `npm run format` / `npm run format:check` — run/check Prettier formatting
- `npm run preview` — preview a production build locally
